# 自主意识（Autonomy）

把 WhaleLife `whalelife-plugin-autonomy` 的「时段 + 概率自行醒来，再由自己决定说不说」搬到 AstrBot，并补上它那块「自主性」面板。

## 它做什么

- 平均每 `平均检查间隔` 分钟掷一次骰子（实际等待有 ±10% 抖动）；
- 掷中才醒，醒来后只把一句「动机」交给主 agent，由它结合人格、记忆与最近上下文判断要不要说话；
- **沉默是合法的**：不说就不调用 `send_message_to_user`，不会发空消息；
- `自适应` 模式下按「距上次活动多久」调概率：刚聊完更安静（×0.15），久没人说话更想开口（×1.5）；
- 睡眠时段内不醒（她自己安排的唤醒可按开关例外）。

醒来借用 AstrBot 原生 cron 的 `active_agent` 任务（一次性、立刻触发），因此系统提示会自动带上「这不是用户消息、别打招呼、需要时用 `send_message_to_user`」这套规则。

## 面板：自主性

**插件页面 → 自主性**（`views/autonomy`，宿主自动发现，不需要额外声明）。

| 区块 | 内容 |
|---|---|
| 唤醒方式 | 总开关、概率模式、平均检查间隔、基础概率、时区、近期与久未活动的阈值/系数、睡眠时段、唤醒动机、唤醒身份；保存后立即生效 |
| 当前状态 | 会话选择（来自 `sessions`，只切换查看对象）、当前普通唤醒概率、上次活动、本次抽取的检查时间、排队与正在判断、她安排的下一次唤醒；两个按钮：现在判断一次 / 结束并取消排队 |
| 最近判断 | 每次自主判断的状态、触发方式、决定，以及它自己写下的理由（面板展示最近 8 条，状态文件保留 20 条） |
| 她安排的唤醒 | 两个开关（允许安排下次唤醒 / 允许突破睡眠时段）+ 取消她已安排的唤醒 |
| 当前会话的意图 | 她记下的约定与念头，以及各自的时间 |

面板数据来自插件状态文件 `data/plugin_data/astrbot_plugin_autonomy/state.json`；面板写入走插件自身配置，保存后热重载本插件，不需要重启容器。直接改磁盘上的 `data/config/astrbot_plugin_autonomy_config.json` 才需要重启。

## 权限：唤醒要用管理员身份跑

自主唤醒的权限由 **cron payload 里的 sender_id** 决定：它落在 `admins_id` 里，本轮才是管理员；否则被判成普通成员，`shell`、`python`、插件目录外的文件读写都会拦下（报 `Permission denied ... for this user role (member)`）。

- 配置里新增 **唤醒身份（`owner_id`）**，默认 `astrbot`，必须出现在 `data/cmd_config.json` 的 `admins_id` 里；
- 想用某个 QQ 号的身份跑，把它填进去（同一个 ID 也要在 `admins_id` 里）；
- 核对办法：唤醒后看她这一轮能不能用 `shell`，或直接看日志里的权限判定。

## 给她的工具

| 工具 | 用途 |
|---|---|
| `autonomy_schedule` | 查/设/取消她自己安排的下次唤醒（要开 `allow_self_wake`；设到睡眠时段要开 `self_wake_during_sleep`） |
| `autonomy_intents` | 记下、修改、完成或放弃意图（约定必须有出处；念头只能写偏好时间） |
| `autonomy_finish` | 结束本轮自主判断并写下理由（只能在自主唤醒的轮次里用；不调用则按轮次结束兜底记一条） |

## 配置项

| 项 | 说明 |
|---|---|
| 启用 | 总开关 |
| 作用会话 | 每行一个 `unified_msg_origin`，如 `astrbot-mc:FriendMessage:<QQ号>`、`astrbot-mc:GroupMessage:<群号>` |
| 平均检查间隔 | 分钟，默认 30 |
| 基础概率 | 每次检查醒来的概率，默认 0.2（≈平均 150 分钟一次） |
| 概率模式 | `固定` / `自适应` |
| 近期阈值 / 系数 | 距上次活动小于阈值时，概率×系数（默认 20 分钟 / 0.15） |
| 久未活动阈值 / 系数 | 距上次活动超过阈值时，概率×系数（默认 360 分钟 / 1.5） |
| 睡眠时段 | `HH:mm-HH:mm`，逗号分隔，可多段；留空表示不设 |
| 时区 | 默认 `Asia/Shanghai` |
| 唤醒时那句话 | 交给主 agent 的动机文案 |
| 唤醒身份 | 管理员用户 ID，须在 `admins_id` 里 |
| 允许她安排下次唤醒 | 默认关 |
| 允许自行唤醒突破睡眠时段 | 默认关 |

## 命令

- `/自主状态` 或 `自主状态`——输出开关、间隔、模式、当前时段是否睡眠，以及每个会话「距上次活动多久、本次概率多少」。

指令受「唤醒前缀」约束：`wake_prefix` 里已含 `/`，任何会话直接发 `/自主状态` 即可；不带 `/` 时则要借其它前缀（如「鲸屿 自主状态」）。

## 排查

- 看日志关键词：`[autonomy] 已启动`、`[autonomy] 掷中，已唤起`、`[autonomy] ... p=... roll=...`（DEBUG 级才会打印每次掷骰结果）。
- 唤醒是否真的说话，看 `Agent 使用工具: ['send_message_to_user']`。
- 面板打不开或一直「读取中」：确认宿主能看到 `views/autonomy/index.html`，以及插件日志里 web API 注册是否报错。

## 停止

面板里关掉「启用」并保存，或删除本插件目录。
