# 自主意识（Autonomy）

把 WhaleLife `whalelife-plugin-autonomy` 的「时段 + 概率自行醒来，再由自己决定说不说」搬到 AstrBot。

## 它做什么

- 平均每 `平均检查间隔` 分钟掷一次骰子（实际等待有 ±10% 抖动）；
- 掷中才醒，醒来后只把一句「动机」交给主 agent，由它结合人格、记忆与最近上下文判断要不要说话；
- **沉默是合法的**：不说就不调用 `send_message_to_user`，不会发空消息；
- `自适应` 模式下按「距上次活动多久」调概率：刚聊完更安静（×0.15），久没人说话更想开口（×1.5）；
- 睡眠时段内不醒。

醒来借用 AstrBot 原生 cron 的 `active_agent` 任务（一次性、立刻触发），因此系统提示会自动带上「这不是用户消息、别打招呼、需要时用 `send_message_to_user`」这套规则。

## 配置项

| 项 | 说明 |
|---|---|
| 启用 | 总开关 |
| 作用会话 | 每行一个 `unified_msg_origin`，如 `astrbot-mc:FriendMessage:<QQ号>`、`astrbot-mc:GroupMessage:<群号>` |
| 平均检查间隔 | 分钟，默认 30 |
| 基础概率 | 每次检查醒来的概率，默认 0.2（≈平均 150 分钟一次） |
| 概率模式 | `固定` / `自适应` |
| 近期阈值 / 系数 | 距上次活动小于阈值时，概率×系数（默认 20 分钟 / 0.15） |
| 久未活动阈值 / 系数 | 距上次活动超过阈值时，概率×系数（默认 360 分钟 / 1.5） |
| 睡眠时段 | `HH:mm-HH:mm`，逗号分隔，可多段；留空表示不设 |
| 时区 | 默认 `Asia/Shanghai` |
| 唤醒时那句话 | 交给主 agent 的动机文案 |

面板改完保存会**热重载**本插件，不需要重启容器；直接改磁盘上的 `data/config/astrbot_plugin_autonomy_config.json` 才需要重启。

## 命令

- `自主状态`（亦可写 `/自主状态`）——输出开关、间隔、模式、当前时段是否睡眠，以及每个会话「距上次活动多久、本次概率多少」。

指令受「唤醒前缀」约束：若你的 `wake_prefix` 不含 `/`，群里请用「前缀 + 自主状态」，私聊可直接发。

## 排查

- 看日志关键词：`[autonomy] 已启动`、`[autonomy] 掷中，已唤起`、`[autonomy] ... p=... roll=...`（DEBUG 级才会打印每次掷骰结果）。
- 唤醒是否真的说话，看 `Agent 使用工具: ['send_message_to_user']`。

## 停止

面板里关掉「启用」并保存，或删除本插件目录。
